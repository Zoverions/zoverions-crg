# Security policy

This repository is a research package, not an autonomous governance or safety authority.

Report vulnerabilities privately through the repository Security tab. Do not include live credentials, private datasets, personal data, or unpatched exploit details in public issues. Include the affected commit, minimized reproduction, impact, and safe proof of concept.

Future governance integrations must preserve human review and appeal; future research datasets require declared provenance, access terms, checksums, and redistribution constraints.
