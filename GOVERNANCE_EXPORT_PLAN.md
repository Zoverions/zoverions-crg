# Governance export plan

Proposed repository name: `generative-landscape-governance`

This is a proposal only. Creating the repository, changing visibility, moving issues, or deleting source files requires separate approval.

## Proposed scope

A decision-support research package for comparing actions against declared optionality, reversibility, participation, and generative-landscape heuristics. It must not claim objective constitutional correctness, universal morality, or automated authority.

## Prepared source set

- `CONSTITUTION.md`
- `zoverions_crg/constitution.py`
- `test_constitution.py`

Exact source sizes and SHA-256 hashes are recorded in `exports/governance-source-manifest.json`. The manifest is an export review set, not permission to copy or remove files.

## Required destination package

- a repository-level status and claim boundary;
- a versioned decision schema and typed result contract;
- unified truth-table and boundary tests;
- counterexamples, disputed cases, and negative findings;
- declared weights/thresholds with sensitivity analysis;
- provenance for every normative assumption;
- human decision/appeal behavior and no autonomous authority;
- explicit license and compatibility review;
- source/destination hash manifest and destination regression evidence.

The current repository retains all files and history until an approved destination passes these gates.
